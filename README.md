# Simulador de Cantina

Sistema de gerenciamento de estoque baseado em uma **Fila de Prioridade** implementada com uma **Lista Duplamente Encadeada**.

---

## Estrutura do Projeto

| Arquivo | Descrição |
| :--- | :--- |
| **product.py** | Define a classe `Product` (Atributos e representação). |
| **pqueue.py** | Contém as classes `PNode` (Nó) e `PQueue` (Lógica da Fila). |
| **main.py** | Ponto de entrada. gera dados fictícios e executa a simulação. |

---

## Como Executar

### 1. Pré-requisitos
* Python 3.10 ou superior.
* Bibliotecas necessárias encontram-se no arquivo `requirements.txt`
